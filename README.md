# About This Repository

## Background

This is a Online Mahjong Simulator developed by [etoile_et_toi.mp3](https://github.com/etoile-et-toi-mp3) and [EasonyehOWO](https://github.com/EasonyehOWO) during the first semester of the 113 academic year (Sept. 2024 ~ Jan. 2025) as a final project for the "Introduction to Network Programming" course, which is instructed by Prof. Li-Hsing Yen (嚴力行) at National Yang Ming Chiao Tung University, Taiwan.

## Purpose

The purpose of this repository is to showcase the acquired skills of the authors and their capability of finishing a functionable project independently. By sharing this content openly, the repository aims to inspire discussions and spark new ideas related to the course's topics and tasks.

## Content

The content in this repository includes the source codes that can be compiled into executable programs for players and servers, makefiles, several state diagrams that describes the workflow of the simulator, and the configured [unpv13e directory](https://github.com/unpbook/unpv13e) provided in the handbook to maintain the environment for developement.
